# 无同花顺 API Key 时支持搜索并添加沪深场内 ETF/LOF

## Goal

当前未配置同花顺 API Key 时，自选股搜索自动降级至东方财富与腾讯公开搜索接口，但两个公开源的响应解析逻辑仅放行 A 股股票与指数，将沪深场内 ETF/LOF（如 `588170`、`510300`、`159915`、`161005`）全部过滤，导致用户搜索无结果且无法加入监控。同时，搜索返回空结果时界面缺少明确提示，场内 ETF 的 3 位小数报价也会被截断为 2 位小数展示。

完成后，无论是否配置同花顺 API Key，用户在「个股监控」中均可按 6 位代码或中文简称正常搜索并添加沪深场内 ETF/LOF，并在悬浮窗 HUD、自选股管理列表与详情分时图中正常查看实时量能、3 位小数价格与告警状态。

## Behavior

**搜索与添加**
- 未配置同花顺 API Key（或同花顺检索不可用）时，降级到东方财富或腾讯公开搜索接口，能够返回匹配的沪深场内 ETF 与 LOF 标的（如 `588170.SH`、`510300.SH`、`159915.SZ`、`161005.SZ`），并支持一键点击「+ 加入自选」。
- 已配置同花顺 API Key 时，原有搜索与添加行为保持正常，且三方搜索源对场内 ETF/LOF 的资产类型语义保持一致。
- 严格排除无盘中分时行情的场外开放式基金（如东财 `OTCFUND` / 非沪深市场编号、腾讯 `jj` 市场前缀）以及港股、美股、北证等非沪深标的。
- 用户输入关键词且检索完成但无匹配项时，搜索区明确显示空结果提示，而非保持空白。

**行情展示**
- 加入自选的场内 ETF/LOF 按现有混合双源链路正常拉取实时快照、今/昨 1 分钟分时基线与放缩量/斜率/告警指标。
- 沪深场内 ETF/LOF（沪市 `50xxxx/51xxxx/52xxxx/56xxxx/58xxxx.SH`、深市 `15xxxx/16xxxx/18xxxx.SZ`）在 HUD、自选管理列表、详情页头部与分时图价格显示中保留 3 位小数；股票与指数保持原有展示精度不变。

## Constraints

- 严格遵守沪深两市总成交额硬不变量（仅 `000001.SH + 399106.SZ`），自选 ETF/LOF 仅参与单标能量与告警计算，绝不影响两市总成交额聚合。
- 不改变既有轮询频率、退避限流策略及 `WatchlistService` 的 `^\d{6}\.(SH|SZ)$` 标的约束。
- 保持 Electron 进程隔离与零 MSVC 编译约束，不引入新第三方依赖。
- 同步更新 `docs/DATA_SOURCES.md` 中东财与腾讯搜索过滤口径说明。

## Out of Scope

- 支持场外开放式基金、港股、美股、北证股票或可转债搜索与监控。
- 手动绕过搜索直接盲输任意代码强制入库。
- 为 ETF 单独定制与股票不同的量能或告警计算公式。

## Acceptance Criteria

- 未配置同花顺 API Key 时，分别通过东财与腾讯公开搜索解析 `588170`、`510300`、`159915`、`161005` 等沪深场内 ETF/LOF 均可返回正确 `symbol` 与中文简称，同时继续过滤场外开放式基金（如 `110011`）及港股等非沪深标的。
- 调度器在无同花顺 API Key 场景下调用 `searchTickers('588170')` 能稳定降级至公开源并返回 `588170.SH`；东财失败时能继续降级至腾讯并返回结果。
- 场内 ETF/LOF 代码通过 `formatPrice` 与图表价格格式化时保留 3 位小数（如 `0.622`），普通股票与大盘指数格式化结果保持原样不变。
- 搜索框输入无匹配关键词且检索完成后，页面展示空态提示，不再静默空白。
- `npm run typecheck`、`npm run test`、`npm run build` 全部通过，且新增单元测试覆盖东财/腾讯/同花顺 ETF 搜索解析、无 Key 调度降级及 3 位小数价格格式化回归用例。
