# 独立复盘回放控制台

## Goal

当前图表上的急放/急缩三角仅来自实盘运行期间落库的告警记录（或开发态命令行 `--replay`），用户刚下载软件或盘后打开查看当天及历史交易日数据时，看不到按配置推演出的急缩放提醒，也无法在桌面界面内交互式重演盘中量能变化或试调告警阈值。

完成后，用户可在详情浮层的独立「复盘回放」页签中选择任意本地已录制交易日，默认即见全天分时能量双图与按配置推演出的全部急放/急缩三角和异动事件流，并可通过完整播控条从 `09:25` 到 `15:00` 逐分钟重演、拖动时间轴定位、临时调参试跑并将满意参数一键应用至实盘，全过程与后台实盘监控完全隔离。

## Behavior

**独立入口与实盘隔离**
- 详情浮层顶部新增独立的「复盘回放」页签作为回放控制台；切入或操作回放控制台时，后台实盘行情轮询、HUD 实时显示及实盘告警通道继续正常运行，互不中断、互不串扰。
- 普通「分时能量」页签保持仅展示真实落库的实盘告警记录；当处于盘后/休市静态复盘且当日无实盘告警记录时，在界面提供清晰提示与一键跳转「复盘回放」控制台的入口（自动带入当前查看标的与该交易日）。

**日期选择、默认全天推演与完整播控**
- 控制台列出本地 SQLite 已录制的所有可用交易日（按日期倒序，标识是否具备昨日对比基线），支持在沪深两市总成交、已启用指数与全部自选股之间切换查看。
- 选中任一交易日后，默认一次性推演至收盘（`15:00`），立即可见全天分时能量双图、全部急放/急缩三角标记与回放异动事件流，无需等待播放完成。
- 播控栏提供：从头播放（`09:25 → 15:00`）、播放/暂停、倍速调节、时间轴进度条拖动定位（Seek）及单步前后退；点击回放异动事件流中的任意记录，自动切换至对应标的并定位到该异动发生的分钟时刻。
- 任意时间轴跳转、单步或从头重播均保持确定性结果（冷启动保护与冷却去重状态与按时间顺序完整推进一致）；某交易日缺失昨日基线或存在分钟缺口时显式展示降级标识，绝不补零。

**独立临时参数调优**
- 控制台内提供可展开/常驻的临时监控与告警参数区，默认继承当前实盘监控配置（全局参数与自选股单股覆写）。
- 用户可在不影响实盘运行的前提下调整回放参数（斜率窗口、放/缩量判定阈值、急放/急缩斜率与倍数阈值、「且/或」组合模式、冷却分钟数），修改后即时重新推演当前交易日并刷新图表三角与回放异动流。
- 提供「重置为当前实盘配置」与「应用为实盘配置」操作：应用后立即持久化并热生效至实盘监控与设置页。

**回放告警反馈与数据隔离**
- 回放产生的告警严格仅存内存并带 `[回放]` 标识，绝不写入实盘 `alert_events` 表，绝不弹出 Windows 系统通知，不影响实盘「异动事件流」未读计数。
- 动态播放逐分钟推进触发急放/急缩时，控制台内实时反馈：图表对应时刻出现急放/急缩三角、回放异动流实时追加条目、控制台顶栏/状态区呈现呼吸高亮。
- 提供独立的回放提示音开关（默认静音）：开启后仅在动态播放推进触发告警时播放现有急放/急缩短提示音；一次性全天推演、拖动进度条 Seek 或单步跳转时不发声。

## Constraints

- 必须复用 `src/core/` 统一领域引擎，保持核心不变量：`000001.SH + 399106.SZ` 聚合口径（不含北证）、`11:30–13:00` 午休折叠、`09:25` 集合竞价独立锚点、`09:30–09:34` 冷启动保护与同方向冷却去重、红涨绿跌视觉规范。
- 回放数据严格来源于本地 SQLite 已录制真实行情，绝不合成数据、绝不对缺失成交额补零；常规腾讯分时补齐可将同次 `day/query` 返回的近 5 个交易日落盘（零额外请求），使刚下载用户即可回放最近多个具备昨日基线的交易日。
- 保持 Electron 进程隔离（`contextIsolation: true`、`nodeIntegration: false`），通过类型安全的 preload IPC 传输独立回放状态与控制指令。
- 保留现有开发态命令行 `--replay` 启动模式与 `npm run verify:replay` 校验脚本的向后兼容性。

## Out of Scope

- 新增第三个独立的回放桌面窗口，或让紧凑 HUD 悬浮窗随详情「复盘回放」页签切入历史回放态。
- 在普通「分时能量」页签中直接混入事后推演的放缩三角，或将回放信号写入实盘 `alert_events`。
- 在回放控制台内单独编辑各只自选股的临时单股覆写阈值（单股覆写仍在「自选股」页签维护，回放默认继承）。
- 联网回补超出免费公开接口时间窗口（近 5 日）的远期历史分钟线，或导出回放报表/视频。

## Acceptance Criteria

- 详情浮层可切换至「复盘回放」页签；在盘中开启与操作回放时，后台实盘轮询、HUD 实时数据与实盘告警均持续正常更新不受影响。
- 刚下载并在盘后启动查看普通「分时能量」页签且当日无实盘告警时，界面展示引导入口，点击即可跳转至「复盘回放」页签并默认呈现当日 `15:00` 全天推演结果（含按配置算出的急放/急缩三角与回放异动流）。
- 回放控制台支持切换本地已录制交易日、切换监控标的、从头播放、播放/暂停、调节倍速、拖动进度条 Seek、单步前后退及点击异动记录定位至对应标的与分钟；Seek 到任意时刻的指标与已触发告警列表与顺序播放至该时刻的结果严格一致。
- 在控制台内修改临时告警参数并触发重演后，图表三角与回放异动流即时反映新阈值结果，且实盘配置与实盘行为未被改动；点击「重置」可还原为实盘配置，点击「应用为实盘配置」后设置页与实盘监控同步生效并持久化。
- 回放全程不向 SQLite `alert_events` 写入任何记录、不弹出 Windows 系统通知；回放提示音默认静音，开启后仅在动态播放推进触发告警时发声，全天直达/拖动 Seek/单步时不发声。
- `npm run typecheck`、`npm run test`、`npm run build` 全部通过，且覆盖回放 Seek 确定性、临时参数覆盖重演、实盘数据零污染及关键 UI 播控交互测试。
